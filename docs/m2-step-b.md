# ステップ B — BERT 採点を端末に載せる

> 実施日: 2026-10-31 / 状態: 実機確認まで完了

## 1. やったこと

| 項目 | 内容 |
|---|---|
| 辞書 | SudachiDict の読み＋コーパスで観測した (読み, 表記) を統合。**22.0万語 / 14.5万読み** |
| 読み替え | 表記ごとに SudachiDict 上の別読みを追加（`にほん → 日本` が入る） |
| 学習データ | 244万文 × 2 epoch。**読み替え拡張**（表記はそのまま読みだけ別読みに差し替え、確率 0.25） |
| モデル | char-level BERT **6層 / 384次元 / 6ヘッド** をゼロから学習（13.7M パラメータ） |
| 量子化 | 動的 int8 → **14.2MB** の ONNX |
| 端末推論 | ONNX Runtime 1.31.1（arm64 のみ） |
| 変換 | 2 段階: unigram ビーム探索（beam 32 / 48仮説）→ 仮説中のスパンだけを BERT 採点 → 再ランク |

学習時間: 約 50 分（RTX 5070 Ti）。候補選択精度 92.05%。

## 2. 精度（検証 1,200 文・端末と同じアルゴリズム）

| 手法 | 文正解率 |
|---|---|
| unigram ビーム探索（BERT なし） | 35.75% |
| 正解が仮説に入っている割合（到達上限） | 70.50% |
| **BERT 再ランク（β=6, fp32）** | **46.25%** |
| **BERT 再ランク（β=6, 出荷する int8 ONNX）** | **46.00%** |

- unigram 比 **+10.25pt**（エラーが 15.9% 減）
- int8 量子化による劣化は **0.25pt** のみ
- β は 6 が最良（4→45.9%, 6→46.25%, 8→45.9%, 12→45.1%）

### 到達上限 70.5% という壁

仮説 48 本の中に正解が入っているのは 70.5%。つまり残り 29.5% は
**探索の段階で落ちている**（BERT では救えない）。ここを上げるには
ビーム幅を増やすか、unigram 以外の手がかりで探索する必要がある。

## 5. 変更点（Android）

- `BertScorer.kt`: ONNX 推論。文脈 64 文字 + 読み 48 文字 + スパン + 候補表記を入力
- `CharVocab.kt`: 文字→id（NFKC 正規化、1文字=1id を保証）
- `LatticeConverter.kt`: 2 段階（ビーム探索 → BERT 再ランク）に変更
- BERT が読めない場合は自動で unigram のみにフォールバック

## 6.5 連接コスト（bigram）を追加

コーパスの単語列から bigram を数え、`-log P(w2|w1)` を連接コストとして
**再ランクの採点にだけ**使う（仮説生成は unigram のまま＝多様性を保つ）。

| 項目 | 値 |
|---|---|
| 語彙 | 6万語 |
| 連接 | 73.2万ペア |
| アセット | 5.22MB（CSR バイナリ） |
| 端末ロード | 128 ms |

### 精度（検証 2,000 文・同一条件）

| 構成 | 文正解率 |
|---|---|
| unigram のみ | 35.95% |
| ＋BERT | 45.45% |
| **＋bigram ＋BERT** | **53.45%** |
| 正解が仮説内（上限） | 70.70% |

bigram は **採点側にだけ**入れるのがコツ。仮説生成に使うとビームが
似た経路に収束して候補の多様性が落ち、かえって悪化した（43.1%）。

### 途中で見つけたバグ

評価スクリプトが `Arc(i, j, c, c.cost)` と書いていて、`extra` にコストを
渡していたため **unigram コストが二重計上**されていた。修正したところ
最適な β が 6.0 → 1.2 に変わり、精度も 49.6% → 53.5% に上がった。
端末側は元々正しい実装だったので、この間ずっと β が実質 2 倍で動いていた。

## 7. 分かったボトルネック: 分割の誤りは BERT では直せない

`きょうは` → `教派` の失敗は、モデルの賢さではなく**構造上の限界**。

- スパン `きょうは` の候補は `教派` の 1 件だけ
- スパン `きょう` の候補には `今日` がある
- モデルの出力は「スパン内での候補どうしの確率」なので、
  **候補が 1 件のスパンは必ず `log P = 0`（無罰）になる**
- したがって `教派`(1語) と `今日`+`は`(2語) を比較できず、unigram の判断
  （`教派` 11.8 < `今日は` 13.2）がそのまま残る

生の logit を使えば比較は可能になるが、全体の精度は
46.0% → 41.8% に落ちた（スパン間で logit の基準が揃わないため）。

つまり **分割の曖昧性を解くには連接コスト（bigram）が要る**。
BERT は「分割が決まったあとの表記選択」で +10pt を出しているので、
役割分担としては設計どおり。
