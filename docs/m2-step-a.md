## 3. 分かったこと（重要）

### 3.1 コーパス由来辞書は「読みの被覆」が足りない

`にほん` が `日本` に変換できない。原因は**辞書に (にほん → 日本) が無い**こと。
Wikipedia 本文では `日本` が `ニッポン` 読みで出現するため、`ニホン` 読みとの組が
コーパスに残らなかった。

```
$ grep '^にほん' data/lexicon.tsv
にほん  にほん  139
にほん  ニホン  96      ← 日本 が無い
```

### 3.2 SudachiDict から辞書を引き直しても、unigram の精度は上がらない

SudachiDict の全エントリ（138.9万 (読み,表記) 組 / 91.2万読み）から辞書を作り直すと
被覆は解決する（`日本` が入る）。しかし文正解率は **38.2% → 33.6% に悪化**した。

理由: 未出現語に既定コストを与える必要があり、その既定値が候補を濁すため。
さらに `にほん` は依然 `に本`（`に` + `本`）に負ける。

```
日本(1語)   cost ≒ 14.0
に + 本     cost ≒  1.6 + 12.2 = 13.8   ← こちらが勝つ
```

単語長ボーナス（`cost -= λ·(文字数-1)`）も試したが、
λ=1.0 で +0.5pt、λ=3.0 では 26.6% まで悪化。**焼け石に水**。

### 3.3 結論：連接コスト（文脈）が無いと実用にならない

これは M0 の分析と一致する。M0 では「文全体の読み」を与えるだけで
候補選択精度が 77.5% → 93.0% に上がった。
つまり **単語の生起確率だけでは足りず、隣接関係＝文脈の情報が本質**。

実在の IME が連接コスト行列を持つのはこのため。そして本プロジェクトでは、
その「文脈を見る部分」を BERT に担わせるのが当初からの設計方針。

## 4. 次のステップ（B）

1. 辞書は SudachiDict 由来に置き換える（被覆のため）
2. その候補集合で BERT 採点器を**再学習**する（今のモデルはコーパス辞書の
   候補集合で学習しているため、辞書を替えたら整合を取り直す）
3. 蒸留（6 層 / 384 次元）→ int8 ONNX → Android へ組み込み
4. `Arc.extra` に `-β·logP_bert` を載せる（実装済みの拡張点を使う）

期待値: M0 の実測で文正解率 +13.9pt。`に本` → `日本` のような誤りは、
文脈を見れば解ける典型例なので、B で直接効いてくる見込み。
