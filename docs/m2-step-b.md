# ステップ B — BERT 採点を端末に載せる

> 実施日: 2026-10-31 / 状態: 実装・オフライン検証まで完了（実機での最終確認は未）

## 1. やったこと

| 項目 | 内容 |
|---|---|
| 辞書 | SudachiDict の読み＋コーパスで観測した (読み, 表記) を統合。**22.0万語 / 14.5万読み** |
| 読み替え | 表記ごとに SudachiDict 上の別読みを追加（`にほん → 日本` が入る） |
| 学習データ | 244万文 × 2 epoch。**読み替え拡張**（表記はそのまま読みだけ別読みに差し替え、確率 0.25） |
| モデル | char-level BERT **6層 / 384次元 / 6ヘッド** をゼロから学習（13.7M パラメータ） |
| 量子化 | 動的 int8 → **14.2MB** の ONNX |
| 端末推論 | ONNX Runtime 1.31.1（arm64 のみ） |
| 変換 | 2 段階: unigram ビーム探索（beam 32 / 48仮説）→ 仮説中のスパンだけを BERT 採点 → 再ランク |

学習時間: 約 50 分（RTX 5070 Ti）。候補選択精度 92.05%。

## 2. 精度（検証 1,200 文・端末と同じアルゴリズム）

| 手法 | 文正解率 |
|---|---|
| unigram ビーム探索（BERT なし） | 35.75% |
| 正解が仮説に入っている割合（到達上限） | 70.50% |
| **BERT 再ランク（β=6, fp32）** | **46.25%** |
| **BERT 再ランク（β=6, 出荷する int8 ONNX）** | **46.00%** |

- unigram 比 **+10.25pt**（エラーが 15.9% 減）
- int8 量子化による劣化は **0.25pt** のみ
- β は 6 が最良（4→45.9%, 6→46.25%, 8→45.9%, 12→45.1%）

### 到達上限 70.5% という壁

仮説 48 本の中に正解が入っているのは 70.5%。つまり残り 29.5% は
**探索の段階で落ちている**（BERT では救えない）。ここを上げるには
ビーム幅を増やすか、unigram 以外の手がかりで探索する必要がある。

## 3. レイテンシ（PC CPU 実測）

| 条件 | 時間 |
|---|---|
| int8, 110文字 / 10スパン | 4.1 ms |
| fp32, 同上 | 4.4 ms |

端末では数倍になる見込み（未実測）。実機で 100ms を超えるようなら
ビーム幅（32→16）を下げる。

## 4. APK サイズ

**46MB**（debug）。内訳:

| 要素 | サイズ |
|---|---|
| `libonnxruntime.so` | 34.2 MB |
| モデル (int8 ONNX) | 14.2 MB |
| 辞書 | 6.4 MB |
| dex | 2.5 MB |

ORT の .so が支配的。`onnxruntime-mobile` 版に替える、または
モデル・辞書を初回起動時のダウンロードにすると大幅に減る。

## 5. 変更点（Android）

- `BertScorer.kt`: ONNX 推論。文脈 64 文字 + 読み 48 文字 + スパン + 候補表記を入力
- `CharVocab.kt`: 文字→id（NFKC 正規化、1文字=1id を保証）
- `LatticeConverter.kt`: 2 段階（ビーム探索 → BERT 再ランク）に変更
- BERT が読めない場合は自動で unigram のみにフォールバック
