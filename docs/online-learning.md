# オンライン学習（薄い出力層のパーソナライズ）

「自分の癖」だけを端末内で学習する仕組み。BERT 本体は凍結したまま、
**最後の薄い線形層（数百次元）だけ**を確定のたびに更新する。

## 仕組み

スコアは次の形になる。

```
スコア = BERT の元スコア + Σ_d w_d · h_d · c_d
```

- `h` = BERT が出したスパンの文脈ベクトル（平均プーリング、単位ベクトルに正規化）
- `c` = 候補表記の文字埋め込み平均（同じく正規化）
- `w` = 端末で学習する重み（384 次元・初期値 0）
- 特徴 `φ = √H · (h ⊙ c)` はノルムがおよそ 1 になるようスケールしてある

`w` が 0 のときは元のスコアと完全に同じ挙動になる（＝学習前は何も変わらない）。

## 更新

確定キー（✓）で語が確定した瞬間、その語について

1. モデルを 1 回 forward して `logits` / `extra` / `φ` を得る（W=1 の軽い推論）
2. 現在の確率 `p = softmax(logits + extra)` を計算
3. 選ばれた候補の確率を上げる方向へ `w` を SGD 更新

```
w ← w - lr · ( Σ_k (p_k - y_k) · φ_k + weight_decay · w )
```

- `lr = 3.0`、`weight_decay = 1e-4`、`|w| ≤ 5` でクリップ
- 更新はバックグラウンドの executor で行い、UI を止めない
- `w` は `SharedPreferences`（`nayuta_online`）に毎回保存

## モデルの入出力

`train/export_onnx_online.py` で書き出す。

```
inputs : input_ids / attention_mask / starts / ends / cand_ids / cand_mask / w
outputs: logits (B,W,K)   元スコア
         extra  (B,W,K)   Σ w_d h_d c_d
         phi    (B,W,K,H) h ⊙ c （学習用）
```

ONNX ランタイムは要求した出力だけを計算するので、

- 通常の変換時は `logits` と `extra` だけを要求（`phi` は刈られる）
- 確定時は `phi` を要求（W=1 なので軽い）

という使い分けができる。

## 効果の確認（実機）

`にほんご` を 4 回続けて「ニホンゴ」で確定すると、以降は何もせずとも
ライブ変換が `ニホンゴ` を出すようになる。学習前は `日本語`。

```
update 1: chosen=ニホンゴ p=0.0019 top=日本語 gap=6.247
update 2: chosen=日本語  p=0.0837 top=ニホンゴ gap=2.391
update 3: chosen=ニホンゴ p=0.0055 top=日本語 gap=5.198
update 4: chosen=ニホンゴ p=0.8947 top=ニホンゴ gap=0.000
update 5: chosen=ニホンゴ p=0.9480 top=ニホンゴ gap=0.000
```

学習後のライブ変換: `にほんご` → **ニホンゴ**（`読み=にほん` は `日本` のまま）

## 設定画面

`パーソナライズ` セクションに学習回数・重みの大きさを表示し、リセットできる。

## 既知の制約

- 学習するのは**単語モードの確定時のみ**（通常の変換確定では語の区切りが分からないため）
- 文脈は「確定前のカーソル前テキスト」を使う
- モデルを再エクスポートした場合、`w` の次元（384）はモデルから読むので追従する
