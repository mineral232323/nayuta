# 文頭 prior-wrong 評価セット（2026-11-07）

## 目的

入力の**先頭の語**は左文脈が無いため、頻度 prior が正解と食い違うと誤変換しやすい。
この層だけを固定して測るための評価セットと指標。

## 生成

```bash
python -m train.make_head_eval
# => data/eval/head_prior_wrong.jsonl
```

条件（既存の wiki2000 / sns2000 から抽出）:

- 文の先頭語（`words[0]`）の読みに候補が 2 つ以上ある
- 正解表記がその候補に入っている
- **最もコストの低い候補（頻度 prior）が正解と異なる**

手作りの代表例（`せんとうの文字の失敗率…` など）も先頭に含む。

現在の構成: **337 文**（wiki 194 / sns 141 / 手作り 2）。
`head` フィールドに `reading` / `gold` / `prior` / `candidates` を持つ。

## 指標

`train.cli eval` が **文頭語正解率** を追加で出す。

- 定義: `予測文.startswith(正解の先頭語)`（文頭の語が正しく変換できたか）
- あわせて通常の文正解率・CER も出る

```bash
python -m train.cli eval --data data/eval/head_prior_wrong.jsonl --limit 0
```

## ベースライン（2026-11-07 時点）

| 条件 | 文正解率 | 文頭語正解率 |
|---|---|---|
| frozen 辞書 + wiki プリセット（bigram 生成 β=0.5） | 0.3709 | **0.5401** |
| frozen 辞書 + device プリセット（unigram 生成 β=1.2） | 0.2700 | 0.4510 |
| new500k 辞書 + 20万語 bigram + device プリセット | 0.3234 | 0.5341 |

※ このセットは「prior が外れる難しい例」だけを集めているので、通常セットの文正解率とは
比べないこと。一般精度は wiki2000 / sns2000 / suru_amb で別途測る。

## 背景（実測）

通常セットで文頭語の頻度 prior が外れる文は wiki 12.4% / sns 5.7% あり、
その層の文頭語正解率は 43〜61% しかなかった（全体は 92〜97%）。
この層を改善するための評価セット。
